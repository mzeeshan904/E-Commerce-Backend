## 📋 Definition of Ready

Before a task can be started, it must meet these criteria:
- [ ] Requirements are clearly defined
- [ ] Acceptance criteria are specified
- [ ] Dependencies are identified
- [ ] Story points are estimated
- [ ] Technical approach is discussed
- [ ] Risks are identified and mitigated

## ✅ Definition of Done

A task is considered complete when:
- [ ] Code is implemented according to requirements
- [ ] Code review is completed and approved
- [ ] Unit tests are written and passing (>90% coverage)
- [ ] Integration tests are added and passing
- [ ] Documentation is updated
- [ ] Security review is completed
- [ ] Performance impact is assessed
- [ ] Code is deployed to staging and tested
- [ ] Product Owner has accepted the work
